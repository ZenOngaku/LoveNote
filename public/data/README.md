# 足迹地图数据（public/data）

「足迹」页的内嵌矢量地图数据。**构建产物，已提交进仓库** —— 运行时不请求任何第三方服务，
从自己域名（Vercel CDN）按需加载，因此在国内网络与微信内置浏览器里都能稳定工作。

## 产物

| 文件 | 内容 | 体积 | 加载时机 |
|---|---|---|---|
| `world.json` | 世界国界粗轮廓（110m，177 个国家/地区，带国界描边） | ~39 KB | 首屏 |
| `world-detail.json` | 中等精度世界国界（10m 源、容差 ≈10 公里；放大后替代粗轮廓） | ~584 KB | tier≥1 惰性加载 |
| `tiles/detail-*.json` | 精细国界分块（16×16 网格，容差 ≈1.2 公里） | 213 块 / 单块 ≤101 KB | 深放大时按视野加载 |
| `china.json` | 中国轮廓（34 个省级 + 南海诸岛/九段线） | ~26 KB | 首屏 |
| `cities.json` | 中国 370 个地级市 + 198 个世界首都点位（含省份名 / 国家名 / 英文名 / 外文名 / 重要度） | ~57 KB | 首屏 |
| `cities-world.json` | 其余约 2400 个世界城市（同样带国家名、英文名与外文名） | ~244 KB | 缩到世界视野或放大时加载 |
| `provinces.json` | 34 个省级边界（放大后显示，同时充当高精度轮廓层） | ~87 KB | tier≥1 惰性加载 |

坐标系：全图层统一 Web Mercator 预投影到 `unit = 8192` 地图单位（世界经度 360° 对应 0..8192），
坐标按图层精度取整（0~1 位小数，1 单位 ≈ 实地球面 4.9 公里）。
运行时只做 `translate/scale`，不做任何投影与几何计算。

## 数据源

- **中国省级边界 / 南海诸岛（九段线）**：[阿里 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector) `areas_v3`
  （`100000_full.json`，含 `100000_JD` 九段线 feature）
- **全国地级市点位**：DataV 各省 `{adcode}_full.json` 中 `level: "city"` 的 feature，
  坐标直接取 `properties.center`（城市驻地经纬度）
- **世界国界**：`world-atlas@2` `countries-110m.json`（Natural Earth 110m，公有领域），
  经 `topojson-client` 转为 GeoJSON
- **世界国界（两级）**：Natural Earth 10m `admin_0_countries`（公有领域）—— 每个国家一个多边形，
  填充 + 描边同时得到「陆地 + 国界线」，中国区域被上层中国图层覆盖、不重复画。
  · `world-detail.json`：全局中等精度（容差 2 单位 ≈ 10 公里），tier≥1 使用；
  · `tiles/detail-<row>-<col>.json`：16×16 分块精细版（容差 0.25 单位 ≈ 1.2 公里）。
    分块用 Sutherland–Hodgman 按块矩形**裁剪**（否则跨多块的大国会在每块里重复一份），
    深放大时一屏通常只落在 1~4 块上 —— 于是「细容差」与「小体积」可以兼得。
    这是矢量瓦片（vector tile）的核心思路，也是主流地图能做到「放大不糊」的原因。
- **全球城市点位**：Natural Earth 10m populated places（公有领域，自带 `NAME_ZH` 中文名），
  经 jsDelivr 镜像获取；中国 / 台湾的城市交给 DataV 数据以避免重复，
  并按 NE 的重要性排序（scalerank ≤ 6）或人口（≥30 万）收敛到约 2000 个，控制体积
- **城市名处理**：中文名统一用 OpenCC 转简体（数据源简繁混用，约 3%）；
  每个世界城市额外带 `en`（英文名）、`lo`（当地外文名，如 東京 / Москва / 서울）与
  `co`（国家中文名）；外文名按国家官方语言从 NE 的 `NAME_JA / NAME_RU / …` 字段取，
  并去掉行政后缀（東京都 → 東京、서울특별시 → 서울）；英语国家（美/英/澳/加等）不存外文名，
  前端只显示「国家 + 英文名」
- **重要度 `r`（越小越重要）**：世界城市取 NE 的 scalerank（0~10）；国内城市省会为 0，
  其余按 DataV 的 `childrenNum`（下属区县数）分档（≥14 → 2、≥12 → 3、≥10 → 4、
  ≥8 → 5，其余 7）。地图在全景档按重要度 + 数量上限决定显示哪些点，放大后才显示全部

## 重新生成

```bash
node scripts/build-geodata.mjs
```

脚本会抓取上述数据源 → 投影 → Douglas-Peucker 简化（各图层容差见脚本 `LAYER_TUNING`）→
写出本文所列产物，并做自检（城市数量、adcode 格式、坐标范围、体积预算），
任一不达标即报错退出。末尾会打印各图层 bbox，可直接对照 `src/lib/map/constants.ts`。

> 说明：`台湾省` 在 DataV 无下级市级数据（404），脚本按「省级中心点」兜底生成一个城市点位；
> `100000_JD`（南海诸岛/九段线）只作为轮廓装饰渲染，不生成可点亮的城市点位。

## ⚠️ 合规说明

- 本项目地图数据**仅供个人记录用途**（情侣二人之间使用），不含审图号。
- 中国地图的公开出版/展示需要标注审图号并使用标准地图；若本应用将来作为**公开产品**发布，
  请把 `public/data/*.json` 换成标准地图的矢量化产物并通过审图流程 —— 前端代码零改动，
  只需替换本目录下的数据文件。
- 世界国界仅为装饰性轮廓（Natural Earth 数据），不代表任何边界主张。
